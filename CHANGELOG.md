# Changelog

All notable changes to this project will be documented in this file.

The initial public release supports **Spotify Connect Ogg Vorbis playback up to
320 kbps**. It does **not** provide Spotify Lossless support.

## [Unreleased]

- Documentation refinements
- Packaging, compatibility, and release-process updates

## [0.1.0] - 2026-08-07

### Added

- Initial public documentation for the packaged CLI release
- Quick start guidance for macOS Intel, macOS Apple silicon, and Windows x86-64
- Firmware compatibility policy centered on 2go firmware 1.6.1
- Install, status, uninstall, recovery, and firmware-update guidance
- License, third-party notices, contribution rules, and security policy
